# Security Policy

## Supported versions

Security fixes are made against the latest supported release line, currently
`0.1.x`. Users should upgrade to the newest available version in that line.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
private vulnerability reporting for this repository if it is enabled. Include
the affected version, steps to reproduce, and a minimal proof of impact. Avoid
attaching real documents or personal data.

If private reporting is unavailable, contact the repository maintainer through
their GitHub profile and request a private security-reporting channel. The
maintainer should enable GitHub private vulnerability reporting in the
repository settings before announcing a public release.
